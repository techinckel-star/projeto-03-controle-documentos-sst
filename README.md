# Projeto 03 — Controle de Documentos de Segurança do Trabalho

## Objetivo

Utilizar inteligência artificial para auxiliar no controle dos vencimentos de laudos ambientais, PGR e PCMSO, além do acompanhamento dos riscos ocupacionais relacionados à NR-1.

## Funcionamento

1. Consultar os documentos e as datas informadas.
2. Identificar documentos vencidos, próximos do vencimento ou em dia.
3. Organizar as pendências e as providências necessárias.
4. Sinalizar situações que precisam de análise dos riscos ocupacionais.
5. Gerar um relatório de acompanhamento.

## Segurança

Todos os dados utilizados neste projeto são fictícios. As informações geradas pela IA devem ser conferidas pela profissional responsável antes de qualquer providência.
